### Print 
``` python
print("Hello World!") # print to console
```
- To print the quotes alternate single and double quotes: 
``` python
print('She said: "Hello" and then left.')
```
- Or use a backslash to escape the character you want to print
``` python
print("She said: \"Hello\" and then left.")
```
- stack overflow - Q & A for programmers.
- Editor shows errors by color highlighting.
### Strings 
- \n (backslash-n) puts line feed in a string 
``` python
print ("Hello world!\nHello World!")
```
``` 
Hello world! 
Hello World!
``` 
- Concatenate strings by + sign
``` python
print ("Hello " + "Angela")
```
- Indentation critical in Python 
- Turn on code intelligence in repl.it settings which shows errors as you're editing your program.
