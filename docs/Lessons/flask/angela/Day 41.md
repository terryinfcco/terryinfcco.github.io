# Day 41

- Lots of HTML tags, but usually only use a few.
- Headings `<h1>` to `<h6>` ==> `<h1>Hello World</h1>`
  - Tags are what's enclosed in angle brackets --> `<h1>`
  - Elements are the whole thing: opening tag, text and closing tag.
- Good practice is having only one `h1` per document
- Good practice is not heading skipping elements. If you have an  `h3` there should also be an `h2`
- Paragraph elements `<p>some test</p>` put separation between elements. Text not in a paragraph element just runs together. Also useful for screen readers.
- Lorem ipsum used to simulate content in a web page. `lipsum.com` has multiple languages.
- Void elements have no content -- `<br />` `<hr />` - note forward slash is after tag name.
- `<br />` line break. `<hr />` horizontal rule (horizontal line)
- Don't use break tags when you should use paragraph elements. Break elements are for things like poems and addresses.
- She recommends using the forward slashes even though HTML5 doesn't require them.
